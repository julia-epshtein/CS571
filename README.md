# Python Virtual Environment Setup

### 1. Set up python virtual environment

#### If you're on **macOS/Linux**:

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

#### If you're on **Windows**:

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```
